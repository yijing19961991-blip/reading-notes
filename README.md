# 个人读书笔记系统

一个有交互性的本地读书笔记网页：**书架 → 点开一本书 → 全书概括 → 点击章节 → 思维导图 + 文字提炼**，并预留每章**音频口播**能力。

## 使用

- 直接双击 `index.html` 即可在浏览器打开（完全离线，无需服务器）。
- 书架点击封面进入书籍页 → 章节目录点击进入章节页。
- 章节页三个标签：**思维导图**（只展示关键词/主要信息，竖向逻辑图布局，适合手机竖屏阅读；节点可点击折叠/展开，工具栏可放大/缩小/适应屏幕）、**文字提炼**（章节完整要点，导图的细节都在这里）、**音频口播**（预留）。
- 已内置示例：《效率为王》（卫哲）+《从优秀到卓越》（吉姆·柯林斯）全书概括与全部章节导图及要点提炼。

## 目录结构

```
读书笔记/
├── index.html             入口
├── assets/
│   ├── css/style.css      样式
│   ├── js/data.js         ★ 全部读书笔记数据（唯一需要日常编辑的文件）
│   ├── js/mindmap.js      思维导图渲染器
│   ├── js/app.js          书架/书籍/章节三个视图 + 路由
│   └── audio/             预留：每章音频口播文件放这里（如 xlw_ch01.mp3）
└── README.md
```

## 新增一本书

1. 在 `assets/js/data.js` 的 `books` 数组里追加一个对象：

```js
{
  id: '唯一英文id',                 // 如 'xlw'
  title: '书名',
  fullTitle: '副标题/一句话定位',
  author: '作者',
  role: '作者简介/身份',
  readDate: '读完日期',
  cover: { from: '#1e4158', to: '#3a7ca5', accent: '#ffd166' },  // 封面渐变色
  tagline: '一句话主旨',
  keywords: ['关键词1', '关键词2'],
  status: '在读',
  summary: ['全书概括第一段', '第二段'],
  chapters: [ … ]                  // 见下方
}
```

2. 每章是一个 chapter 对象：

```js
{
  id: 'ch01', no: 1, title: '章节名',
  tagline: '一句话导语',
  keywords: ['关键词'],
  audio: null,                      // 暂无音频；有音频时填入 { title:'口播标题', src:'assets/audio/xlw_ch01.mp3' }
  mindmap: {                        // 思维导图，树形结构
    t: '根节点文字',
    c: [
      { t: '主干一', c: [ { t: '分支' } ] },
      { t: '主干二' }
    ]
  },
  notes: [                          // 主要文字提炼
    { h: '小节标题', items: ['要点1', '要点2'] }
  ]
}
```

3. 刷新页面即生效。书架、书籍页、章节页全部自动生成。

## 音频口播

- 把 MP3 放入 `assets/audio/`，在对应章节的 `audio` 字段填 `{ src: 'assets/audio/<文件名>.mp3' }`。
- 无音频时章节页自动显示"制作中"占位卡片，不影响其余功能。

## 后续可升级方向

- 对标小程序：数据已与视图完全分离，将来可平移为页面化/小程序数据源。
- 加"已读进度"、书评打分、便签批注等，只改 `app.js` 或加一个存储层即可。
