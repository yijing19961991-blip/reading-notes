# 2026-09-06

## 目标
用《效率为王》为示例，搭建个人读书笔记系统：书架 → 全书概括 → 每章思维导图 + 文字提炼，预留每章音频口播。

## 完成
- 方案：交互式静态网页（推荐理由：零部署、双击即用、离线可用、数据驱动可平移到小程序；小程序需注册审核，对个人笔记过重）。
- 从 `效率为王主要内容.docx` 提取全文（无 pandoc，手动解 zip 解析 document.xml）。
- 产物：
  - `index.html` + `assets/css/style.css` + `assets/js/{data,mindmap,app}.js`
  - `data.js` 编入《效率为王》全书概括 + 10 章思维导图树 + 文字提炼；每章预留 `audio` 字段
  - 章节页三标签：思维导图（可缩放/可折叠节点）、文字提炼、音频口播占位
  - `assets/audio/` 预留目录
- 验证：macOS 无 node，用 JXA（`osascript -l JavaScript`）+ 自写 DOM 桩驱动三个视图全流程冒烟；再用 headless Chrome `--dump-dom` 核验每章节点/连线渲染无 JS 报错。

## 经验
- 本机没有 node/pandoc：docx 提取用 `unzip` + 正则清洗 `word/document.xml` 即可；JS 语法与行为验证用 macOS 自带 JXA，给 `window/document/location/localStorage` 做最小桩即可驱动整页逻辑，比装 node 更快。
- 模型不支持读图：headless Chrome 截图无法人工核对，改用 `--dump-dom` 断言 DOM（节点数、连线数、关键文案），更可脚本化。
- 思维导图布局：右向树，叶节点纵向堆叠后父节点取首尾叶中点，简单稳定，中文按 charCode 估宽换行。
